# Singfolio 要件定義

## 1. 概要

**Singfolio** は、歌う人のためのレパートリー管理アプリ。

カラオケ、弾き語り、歌配信、ライブなどで、
「歌える曲」「練習中の曲」「歌いたい曲」を管理する。

将来的には自分のレパートリーをWebで公開し、
視聴者や友人から「この曲を歌って」というリクエストを受け取れるようにする。

**Tagline**
> Your songs, ready to sing.

**日本語コンセプト**
> 歌える曲を、ひとつの場所に。


## 2. コンセプト

Singfolioが管理するのは「歌の点数」ではなく、**自分が何を歌えるか**。

以下を中心体験とする。

1. **Manage** — 歌える曲・練習曲を管理する
2. **Show** — 自分のレパートリーを人に見せる
3. **Request** — 歌ってほしい曲をリクエストしてもらう
4. **Grow** — 練習してレパートリーを増やす

採点・ランキング・歌唱分析は扱わない。


## 3. 対象ユーザー

- カラオケが好きな人
- 弾き語りをする人
- 歌配信をする人
- ライブ・イベント等で歌う人
- 自分の持ち曲を整理したい人


## 4. 曲データ

各曲は以下の情報を持つ。

- 曲名
- アーティスト
- ステータス
  - Ready（歌える）
  - Practice（練習中）
  - Want（歌いたい）
- 自分のキー
- タグ
- 非公開メモ
- 登録日

曲名・アーティスト以外は基本的に任意入力とする。


## 5. v1.0 機能

### Songs

レパートリー一覧。

- 曲の追加・編集・削除
- Ready / Practice / Want の管理
- 曲名・アーティスト検索
- タグによる絞り込み
- 並び替え

### Practice

練習中の曲を一覧表示する。

練習が完了した曲を `Ready` に変更できる。

### Show Mode

他人にスマートフォンを見せるための閲覧専用モード。

- Readyの曲を表示
- 曲名・アーティスト検索
- タグによる絞り込み
- 編集情報・非公開メモ等は表示しない


## 6. 将来機能

### Public Profile

ユーザーごとの公開URLを発行する。

例：

`singfolio.app/username`

アプリをインストールしていない人でもブラウザから閲覧可能。

### Requests

公開プロフィールからReadyの曲に対して、

**Request**

を送信できる。

将来的にはレパートリーに存在しない曲へのリクエストにも対応する。

リクエストされた曲を、

`Want → Practice → Ready`

と育てられる仕組みを目指す。


## 7. 対象外

以下はSingfolioでは扱わない。

- カラオケ採点
- DAM / JOYSOUNDのスコア管理
- 全国ランキング
- 歌唱分析
- 録音
- 楽曲再生
- SNSタイムライン
- コメント・DM


## 8. UI / ブランド

### Brand

**Name:** Singfolio  
**Concept:** Sing + Portfolio

### Visual

- 白を基調としたクリーンなUI
- Light / Dark Mode対応
- Mint × Purpleをブランドカラーとする
- B2「音符 + リスト」シンボルをブランドマークとする
- 大量の曲を扱いやすいリスト中心のUI
- アルバムアートを主役にしない

### Language

- English First
- 日本語対応
- 将来的な多言語化を前提とする


## 9. 基本画面

v1.0：

1. Songs
2. Song Detail / Edit
3. Practice
4. Show Mode
5. Profile / Settings

将来：

6. Public Profile（Web）
7. Requests


## 10. Singfolioの原則

> **何点取れるかではなく、何を歌えるか。**

Singfolioは、歌う人が自分のレパートリーを管理し、
それを誰かに見せ、次に歌う曲へつなげるためのアプリとする。
